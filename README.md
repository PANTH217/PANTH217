### 🚀 Key Projects

#### 🛡️ [AI Login Anomaly Detector](https://daiict-hack1-aianomal.onrender.com)
* A cybersecurity platform built for a hackathon at **DA-IICT** that detects suspicious login activity.
* **Tech Stack:** Streamlit (Python), FastAPI (Python), Plotly, Folium Maps.
* **Key Features:** Geofencing, risk scoring (using gauges), impossible travel detection, and automated risk factor reporting.

#### 🌌 SpaceScope
* A full-stack astronomical exploration platform featuring interactive visuals and NASA dataset integrations.
* **Tech Stack:** MongoDB, Express.js, React, Node.js (MERN), Google OAuth.
* **Key Features:** User-specific exploration dashboards, robust Google Authentication, and responsive design.

#### 🛰️ UrbanOrbit
* A real-time citizen-led urban issue logging and tracking platform.
* **Tech Stack:** React, Firebase Auth, Firestore Database.
* **Key Features:** Live issue reporting, real-time database updates, authentication, and status monitoring.

#### 🔔 Guardian AI Fall Detection
* An intelligent safety system designed for real-time fall detection and automated alert routing.
* **Tech Stack:** Python, AI/ML models, IoT integrations.

#### 🚗 Smart Parking Lot System
* A Java-based desktop application for managing vehicle flow and automated rate calculations.
* **Tech Stack:** Java, Swing/AWT GUI.
